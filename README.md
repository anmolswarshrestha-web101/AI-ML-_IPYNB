# AI/ML Notebooks

A collection of Python notebooks where I practice machine learning, data analysis, and NLP.

## Notebooks

| Notebook | What it covers |
|---|---|
| beginner_ml_notebook.ipynb | Beginner machine learning workflow |
| learn_numpy.ipynb | NumPy fundamentals |
| nepal_data_cleaning.ipynb | Cleaning and preparing Nepal-related data |
| BMW_Analysis.ipynb | Exploratory analysis of BMW data |
| laptop_analysis.ipynb | Exploratory analysis of laptop data |
| zomato_analysis.ipynb | Exploratory analysis of Zomato data |
| heart_attack_analysis.ipynb | Analysis of heart attack dataset |
| weaher.ipynb | Weather data analysis |
| analysis.ipynb | General data analysis |
| Custom_FAQ_Chatbot_100_Questions.ipynb | Custom FAQ chatbot built on 100 questions |

## Tools
Python, Pandas, NumPy, Matplotlib, Jupyter Notebook

## How to run
1. Clone the repo: `git clone https://github.com/anmolswarshrestha-web101/AI-ML-_IPYNB.git`
2. Install Jupyter: `pip install notebook pandas numpy matplotlib`
3. Run `jupyter notebook` and open any file.
